Developer Workflow

From zero to live game on the store. Follow each step in order.

1. Setup

One-time setup. Takes about 2 minutes.

1

Install the CLI

Requires Node 22+.

npm install -g @freegamestore/cli
2

Sign in with GitHub

Device-flow OAuth. No password leaves your terminal.

fgs login

2. Build

Scaffold a template, then build your game.

3

Scaffold from a template

Pick a template: canvas, grid, cards, 3d, phaser, kaplay, pixi, or babylon.

fgs init my-game --template canvas
4

Install and run

Hot reload at localhost:5173.

cd my-game && pnpm install && pnpm dev
5

Build your game

Edit web/src/App.tsx. Use any AI tool or code by hand. The template's CLAUDE.md points AI agents to the platform guide automatically.

AI-first: Open Claude Code, Cursor, Copilot, or any tool in the project folder. Describe your game and the agent builds it using the platform's design system, SDK, and conventions.

3. Verify

Make sure your game meets platform requirements before publishing.

6

Run compliance checks

Catches missing LICENSE, brand font issues, tracking SDKs, oversized bundles, missing PWA manifest, viewport overflow, and more.

fgs check

Fix any failures. Warnings are recommendations. Re-run until all hard checks pass.

4. Publish

One command provisions everything: GitHub repo, hosting, DNS, store listing.

7

Publish to the store

Runs compliance checks, then provisions your game. You'll be prompted for a name, category, and description.

fgs publish

This creates:

  • GitHub repo at freegamestore-online/my-game
  • Hosting route for my-game.freegamestore.online
  • Store listing on the storefront
  • You as a collaborator with push access
8

Push your code

The publish output tells you the remote URL. Add it and push.

git remote add upstream https://github.com/freegamestore-online/my-game.git git push upstream main
9

Game is live

GitHub Actions builds and deploys to R2 in ~30 seconds. Your game is now at:

https://my-game.freegamestore.online
Auto-deploy: Every future push to main deploys automatically. No manual steps needed.

5. Update

The ongoing loop: code, push, deployed.

↻

Edit → Push → Live

Make changes locally, commit, push to main. Live in ~30 seconds. Run fgs check before pushing to catch issues early.

git add -A && git commit -m "add power-ups" && git push upstream main

CLI Reference

fgs login Sign in with GitHub
fgs init <id> Scaffold a game from a template
fgs check Run compliance checks
fgs publish Provision and publish to the store
fgs list See your published games
fgs logs <id> Tail deployment logs
fgs doctor Health check (Node, git, pnpm, auth, API)
fgs screencheck Verify game fits viewport in real browser
