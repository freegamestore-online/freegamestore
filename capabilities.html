Platform Capabilities

Everything you get when you build on FreeGameStore. One SDK, zero infrastructure, free forever. For the raw browser APIs these build on, see Browser APIs.

Included free

Free

GameShell

Full-viewport game container. Locks to 100svh, prevents scroll, manages safe areas. Your game fills the screen. <GameShell>

Free

GameTopbar

Brand-consistent topbar with score, timer, and custom stats. Back button, theme toggle, sound toggle built in. <GameTopbar score={42} />

Free

Auth (Google OAuth)

One-click sign in via auth.freegamestore.online. SSO across all games. Session persists in localStorage. useAuth()

Free

Leaderboards

Global leaderboards backed by D1. Submit scores, fetch top entries, show player rank. useLeaderboard()

Free

Sound System

Game audio with mute toggle that persists. Respects user preference across sessions. useGameSounds() / useSound()

Free

Game Over Screen

Standard game-over overlay with score, personal best, play again, and leaderboard submit. <GameOverScreen>

Free

UI Kit (14 components)

GameButton, GameModal, GameConfirm, GameAuth, GameThemeToggle, GameTextSizeToggle, Leaderboard, and more. All dark-mode aware.

Free

Dark Mode + Text Size

System-aware dark mode with manual toggle. Text size adjustment for accessibility. Persists in localStorage.

Free

Static Hosting (R2)

Push to main = live. GitHub Actions builds, uploads to R2. Zero egress fees. Sub-50ms globally. *.freegamestore.online

Free

Game Templates

Canvas, 3D (Three.js), Grid, Cards, Phaser, Kaplay, PixiJS, Babylon.js. Pre-configured with SDK, topbar, and deploy pipeline.

Free

CLI + Compliance

fgs init, fgs check, fgs publish. Automated brand, bundle size, PWA, dark mode, and viewport checks on every push.

Free

Quality Dashboard

Public quality scores for every game. Compliance checks, audit results, and last-updated dates visible to players.
