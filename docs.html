Documentation

Everything you need to build a game. One SDK, brand-consistent, scroll-free.

Quick Start

npm i @freegamestore/games
import { GameShell, GameTopbar } from '@freegamestore/games'

export default function App() {
  return (
    <GameShell topbar={<GameTopbar title="My Game" score={0} />}>
      {/* your game canvas */}
    </GameShell>
  )
}

GameShell

Root layout wrapper. Locks the viewport to 100svh, prevents document scroll, disables text selection. Every game wraps its content in this.

<GameShell topbar={<GameTopbar title="Tetris" score={42} />}>
  <TetrisBoard />
</GameShell>
PropTypeDescription
topbarReactNode?Topbar element (typically GameTopbar)
childrenReactNodeGame content, fills remaining viewport

GameTopbar

Standard topbar for all games. Same font, padding, and colors everywhere.

// Simple: just a score
<GameTopbar title="Snake" score={42} />

// Custom stats + play/pause + rules
<GameTopbar
  title="Pac-Man"
  stats={[
    { label: 'Score', value: 1200, accent: true },
    { label: 'Lives', value: 3 },
    { label: 'Level', value: 5 },
  ]}
  rules={<p>Eat all the dots. Avoid ghosts.</p>}
  onPlayPause={togglePause}
  paused={isPaused}
  onRestart={restart}
  actions={<><GameThemeToggle /><GameTextSizeToggle /></>}
/>
PropTypeDescription
titlestring?Game name, left side
scorenumber?Convenience for single-score games
statsGameTopbarStat[]?Custom stat lineup (replaces score)
actionsReactNode?Right-side buttons (max 2)
rulesReactNode?Instructions, shows info icon overlay
onPlayPause() => void?Renders play/pause button
pausedboolean?Controls play/pause icon state
onRestart() => void?Renders restart button

GameOverScreen

Standard game-over overlay with score, high score, and play again button. Renders on top of the game board.

<GameOverScreen
  score={42}
  highScore={100}
  onPlayAgain={() => reset()}
/>

GameModal

Fullscreen modal for rules, settings, confirmations. Closes on backdrop click or Escape.

<GameModal open={showRules} onClose={() => setShowRules(false)} title="Rules">
  <p>Eat dots. Avoid ghosts. Collect power pellets.</p>
</GameModal>

GameConfirm

Confirm/cancel dialog for quit, restart, or destructive actions.

<GameConfirm
  open={showQuit}
  title="Quit Game?"
  message="Your progress will be lost."
  confirmLabel="Quit"
  variant="danger"
  onConfirm={quit}
  onCancel={() => setShowQuit(false)}
/>

GameButton

Standard game button. Four variants, three sizes.

<GameButton variant="primary" size="lg" onClick={start}>Play</GameButton>
<GameButton variant="secondary" size="md">Settings</GameButton>
<GameButton variant="danger" size="md">Quit</GameButton>
<GameButton variant="ghost" size="sm">Skip</GameButton>

GameAuth

Sign-in button. Google OAuth via the FGS auth worker.

<GameAuth />

GameThemeToggle + GameTextSizeToggle

Compact toggles for the topbar actions slot. 28px square, no props.

import { GameThemeToggle, GameTextSizeToggle } from '@freegamestore/games'

<GameTopbar
  title="Chess"
  actions={<><GameThemeToggle /><GameTextSizeToggle /></>}
/>

Leaderboard

Renders a leaderboard table. Pass entries from useLeaderboard().

<Leaderboard entries={entries} />

Hooks

useLeaderboard

Submit scores and fetch rankings from the FGS leaderboard worker.

import { useLeaderboard } from '@freegamestore/games'

const { submitScore, entries, loading } = useLeaderboard('tetris')

// On game over:
await submitScore(42)

useAuth

Google OAuth state. Used internally by GameAuth. Rarely needed directly.

const { user, signIn, signOut } = useAuth()

useGameSounds

Synthesized sound effects for common game events.

const sounds = useGameSounds()

sounds.move()     // piece moved
sounds.rotate()   // piece rotated
sounds.drop()     // piece dropped
sounds.clear()    // line cleared
sounds.levelUp()  // level up
sounds.gameOver() // game over

useSound

Low-level sound context. Mute/unmute state shared across all hooks.

const { muted, toggleMute } = useSound()
